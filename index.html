Missions

Mission Proposal: Unreliable Wi-Fi in a Basement Workspace

Context: In a basement-level workspace at a university where I work, the Wi-Fi connection drops often and some areas have no signal at all. This affects the students and staff who work there.

Action: As an employee, I don't have access to the network equipment, so I did not try to fix it myself. I reported the problem to an IT staff member I work with and described the symptoms and who was affected. I then wrote a mission proposal recommending that a network technician assess the area and fix the coverage.

Evidence: Mission proposal document (sanitized).

Result / Reflection: The problem improved, but some areas are still unreliable. I learned to stay within my access level and escalate to the right people. Next time, I would submit a formal ticket with the location, time, and number of users affected, so the issue is tracked and documented.

Skills Demonstrated: Problem identification, escalation, professional communication, mission proposal writing.

Knowledge Article: ACE Standard Workstation Reference

Action: I wrote a reference article so any technician can confirm a workstation matches the standard before troubleshooting. I validated it on a real computer, using ipconfig to check the network settings.
